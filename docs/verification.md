# 검증 안내

이 저장소의 검사는 지원서 웹사이트를 대상으로 합니다. 소개된 다른 프로젝트의 테스트 실행을 대신하지 않습니다.

## 검사별 범위

| 명령                   | 확인하는 것                                                   |
| ---------------------- | ------------------------------------------------------------- |
| `npm run check`        | 콘텐츠 구조, 타입, 린트, 포맷, 단위·컴포넌트 테스트           |
| `npm run build`        | 실제 공개 콘텐츠 검증, 프로덕션 빌드, 콘텐츠 manifest 일치    |
| `npm run test:release` | 격리된 콘텐츠로 공개 빌드하고 초안·보관 본문의 제외 여부 확인 |
| `npm run test:e2e`     | 실제 브라우저에서 탐색·반응형·키보드·접근성 관련 동작 확인    |

단위 테스트는 날짜 경계와 겹침 배치, Markdown 검증, Notion 변환·충돌·복구 등을 다룹니다. 컴포넌트 테스트는 목록·상세·이미지·포커스 같은 화면 동작을 확인합니다.

E2E는 사용자 원고와 독립된 fixture로 실행합니다. Chromium에서는 전체 시나리오를, Firefox·WebKit에서는 핵심 읽기 흐름을 확인합니다. 제목과 기간 막대 선택, 직접 URL·새로고침·뒤로가기, 다음 경험, 키보드 이동, 1440·1024·768·390·320px 화면을 포함합니다. 실제 자료 파일의 치수와 메타데이터 일치, 이미지 비율·갤러리·기술 스택 표시도 검사합니다.

글자 크기 200%와 실제 브라우저 확대 200%는 다른 조건으로 검사합니다. 실제 확대는 격리된 테스트 브라우저의 확장 API를 사용하며 사용자 브라우저 설정은 바꾸지 않습니다. 모션 감소 설정과 axe 검사도 포함하지만, 자동 검사 통과가 모든 접근성이나 실제 사용성을 보장하지는 않습니다.

## 실행

Node.js 24에서 의존성과 테스트 브라우저를 설치합니다.

```bash
npm ci
npx playwright install chromium firefox webkit
npm run check
npm run build
npm run test:release
npm run test:e2e
```

프로덕션 결과는 `dist/`, E2E용 빌드는 `dist-qa/`로 분리됩니다. 로컬 브라우저 결과와 격리된 공개 빌드 자료는 프로젝트 기준 `../../work/qa/`에 기록하며 실제 콘텐츠를 시험 문구로 덮어쓰지 않습니다.

CI는 실제 공개 빌드와 fixture 검사를 모두 실행합니다. 브라우저 테스트 결과는 CI에서 `test-results/`에 저장하며, 작업이 실패했을 때 존재하는 trace·스크린샷을 `browser-test-failures` artifact로 7일간 보관합니다. 성공한 실행에서는 해당 artifact를 올리지 않습니다.

## 결과를 설명하는 기준

- **구성됨:** 검사 코드와 실행 설정이 존재합니다.
- **실행됨:** 특정 리비전에서 명령을 실행한 기록이 있습니다.
- **통과함:** 해당 실행의 성공 결과를 확인했습니다.

[GitHub 검사 기록](https://github.com/swaan-kim/fe-application-timeline/actions/workflows/ci.yml)에서 검토하려는 커밋과 실행 결과를 함께 확인하세요. README에는 변경될 수 있는 테스트 개수를 고정된 성과로 적지 않습니다.

공개 전에는 자동 검사 외에도 실제 자료와 문장을 읽어보며 이미지·제목 크기와 흐름을 확인합니다. 배포 후 확인은 [배포 안내](deployment.md)를 따릅니다.

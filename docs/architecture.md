# 구조와 구현 판단

목표는 기능을 많이 제공하는 것이 아니라, 경험을 훑고 읽고 다시 탐색하는 흐름을 유지하는 것입니다.

## 콘텐츠와 화면을 분리한 이유

경험별 Markdown → 빌드 시 검증·공개 항목 선택 → 타임라인·목록·상세 화면

경험의 제목과 본문을 고칠 때 UI 코드를 수정하지 않도록 했습니다. 같은 데이터에서 목록과 상세를 만들기 때문에 제목·기간을 여러 곳에 중복 입력하지 않습니다. 파일명은 상세 URL의 ID로 사용합니다.

개발 환경에는 초안도 표시하지만, 공개 빌드에는 게시 항목과 명시적으로 승인한 초안만 포함합니다. 빌드 후에는 콘텐츠 목록·상태·본문 해시를 다시 확인합니다. Notion 가져오기는 편집 도구이며 사이트 실행에 필요하지 않습니다.

## 날짜 규칙과 화면 배치를 나눈 이유

날짜 위치 계산, 유효성 검사, 겹치는 기간의 하위 트랙 배치는 순수 함수로 관리합니다. 시작일·종료일·ID 순서에 따라 결정적으로 배치하므로 같은 입력에서 같은 결과를 얻습니다.

화면에서는 막대의 실제 날짜 비율과 제목을 읽을 공간을 따로 확보합니다. 제목과 막대는 하나의 링크이지만, 긴 제목 때문에 기간 막대 자체를 늘리지 않습니다. 목록과 다음 경험은 같은 정렬 규칙을 사용합니다.

## 화면을 나누되 탐색을 이어가는 방법

홈과 상세는 독립된 경로를 사용합니다. 상세 페이지와 Markdown 렌더러는 지연 로딩해 홈의 초기 코드에서 분리합니다. 로딩에 실패하면 다시 시도하거나 목록으로 돌아갈 수 있습니다.

상세 화면의 종이 폭과 상단 돌아가기 링크는 본문보다 먼저 표시하고, 로딩·실패·완료 상태에서 같은 요소를 유지합니다. 느린 연결에서도 링크 위치가 바뀌거나 키보드 포커스가 사라지지 않도록 하기 위해서입니다.

상세에서 목록으로 돌아올 때는 해당 경험의 hash를 이용해 위치와 포커스를 복원합니다. 다음 경험은 홈과 같은 Build → Work → Grow, 분류 안에서는 최신순이며 마지막 항목에서 처음으로 순환하지 않습니다. 차트를 건너뛰는 키보드 링크도 제공합니다.

화면 폭이 줄어 선택 중인 차트가 숨겨지면, 같은 경험의 목록 행으로 포커스를 옮기고 화면 안에 보이도록 합니다. 돌아온 행에는 분류 색의 옅은 배경을 표시하고, 상세 하단에는 다음 경험임을 알 수 있는 짧은 라벨을 둡니다.

768px 미만에서는 차트를 숨기고 같은 경험 목록을 세로로 보여줍니다. 자료의 원본 치수를 메타데이터로 관리해 로딩 전에 공간을 확보합니다. 강아지 스마트폰 캡처만 최대 높이 36rem으로 제한하며 자르지 않습니다. 다른 자료와 미등록 이미지는 기존 표시 방식을 유지합니다.

기술 로고는 Devicon의 SVG를 로컬에서 제공합니다. 출처·고정 리비전·MIT 라이선스는 `public/media/technologies/`에 보관합니다. 로고를 내려받기 위한 외부 CDN 요청은 없습니다.
